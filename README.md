## 🎨 Identidade Visual & Design System

- **Paleta de Cores:** Fundo escuro profundo (`#06080e`, `#0a0d18`), superfícies com glassmorphism translúcido (`backdrop-filter: blur(14px)`), detalhes em azul elétrico (`#3b82f6`, `#60a5fa`) e roxo neon (`#8b5cf6`, `#a78bfa`).
- **Tipografia:** `Inter` (sans-serif moderna para leitura confortável) e `JetBrains Mono` (monospace para códigos, badges e elementos de terminal).
- **Efeitos e Microinterações:**
  - Rede tecnológica de partículas interativas no HTML5 Canvas (otimizada com `requestAnimationFrame` e responsiva ao cursor).
  - Terminal interativo no Hero com código de configuração simulado.
  - Filtros dinâmicos nos cards de projetos (Todos, Front-end, Back-end, Java, Full Stack).
  - Mockups visuais estilizados em CSS/SVG para cada projeto, sem imagens externas quebradas.
  - Animações suaves de entrada (Scroll Reveal com `IntersectionObserver`).

## 🛠️ Como Testar Localmente

O portfólio foi construído com tecnologias web puras (Vanilla HTML, CSS e JavaScript), dispensando ferramentas pesadas de build para visualização imediata:

1. **Abrir diretamente no navegador:**
   - Dê um duplo clique no arquivo `index.html` ou clique com o botão direito e selecione seu navegador preferido.

2. **Utilizando a extensão Live Server do VS Code:**
   - Abra a pasta do projeto no VS Code.
   - Clique com o botão direito em `index.html` e selecione **Open with Live Server**.

3. **Ou via Node.js / npx:**
   ```bash
   npx serve .
   ```

## ☁️ Como Publicar na Vercel

O projeto já contém o arquivo `vercel.json` configurado:

1. Envie os arquivos para o seu repositório no GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: portfolio caua nascimento sanches"
   git branch -M main
   git remote add origin https://github.com/37661-hue/portfolio-caua.git
   git push -u origin main
   ```
2. Acesse [vercel.com](https://vercel.com) e faça login com seu GitHub.
3. Clique em **Add New...** > **Project** e importe o repositório.
4. Clique em **Deploy**. Seu portfólio estará online em segundos com HTTPS e CDN global!
